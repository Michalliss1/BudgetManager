BudgetManager
Personal Finance Manager built with Python and Kivy.

Project Overview
BudgetManager is a personal finance application developed in multiple stages.

The project started as a console application and later evolved into a mobile application built with Kivy for Android.

Features:

Expense tracking
Fuel expense tracking
Expense history
Daily statistics
Monthly statistics
Undo recent entries
JSON data storage
Android APK builds

Technologies:

Python
Kivy
JSON
Buildozer
GitHub Actions

Project Structure:

main.py – console version
main_kivy.py – mobile version
walidacja.py – input validation
json_manager.py – data storage
statystyki.py – statistics
funkcje.py – business logic

Planned Improvements:

OOP refactoring
SQLite database
